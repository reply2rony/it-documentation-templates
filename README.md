# IT Documentation Templates

Templates for the documents an IT team writes every month: standard procedures, a vendor register, and a monthly IT report. Good documentation is what turns one person's knowledge into a team's knowledge.

## Files
- `templates/sop-template.md` — use it for every procedure, so all SOPs look the same.
- `templates/vendor-register.csv` — one row per vendor, with contact and contract dates.
- `templates/monthly-it-report-template.md` — the monthly report to management.
- `templates/incident-summary-template.md` — a one-page summary of the month's incidents.
